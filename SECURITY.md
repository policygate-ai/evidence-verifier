# Reporting a security problem

If you find a security problem in this repository, for example a pack that `verify-evidence.py` accepts although it
should fail, or a difference between SPEC.md and the code that weakens a check, please report it privately.

Use GitHub private vulnerability reporting on this repository: open the **Security** tab and choose
**Report a vulnerability**. Only the maintainers can see the report.

Please do not open a public issue for a security problem.

A useful report says:

- what you did (the command, and a pack or the steps to build one, if you can share it);
- what you expected;
- what happened.

Problems that are not about security, such as unclear wording or a crash on a valid pack, can go in a normal
issue.
